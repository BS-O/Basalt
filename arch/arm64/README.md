# arch/arm64 —— 兼容预留（ADR-006）

本目录为 arm64 架构适配层**占位**，当前**不包含任何实现**（无汇编、无启动代码、无驱动）。

设计意图（未来移植时落地）：

- 对称实现 `arch/x86/` 暴露的同一组接口：console sink（架构提供的输出通道）、io/MSR 等原语按 arm64 语义替换、halt/中断控制；
- 引导层在 `boot/arm64/`（对应 x86 的 Limine 请求标记 + 64 位入口桩）；
- 内核主体（kmain、console 抽象、lib/）架构无关，直接复用；
- 构建系统届时新增 arm64 目标与交叉工具链变量。

本里程碑构建系统不含 arm64 目标，条件编译桩以 `#if defined(__aarch64__)` 预留。
