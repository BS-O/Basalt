从裸机开始构建的自研 x86-64 内核。Limine 负责固件初始化，内核自身代码从 64 位长模式入口开始，直至在屏幕上画出第一个字符。

M0 里程碑已达成 · Limine v12.10.0 · C++17 / C11 / GNU as · make check 全绿

M0：启动，然后说出第一句话。

Limine 完成全部固件初始化；Basalt 的第一行汇编自长模式入口开始。

为什么值得读、值得写。

M0 严格限定"能启动 + hello world"，但工程方法与扩展接口按真实内核的标准预留。

三语言严格分层

汇编只做入口桩，C 守住硬件边界，C++ 只出现在子系统层。跨语言一律 extern "C"，单向依赖——每一层都能单独讲清楚。

headless 可验证

make check 十五秒冒烟断言串口输出；QEMU 监视器 screendump / 寄存器 / 异常日志三板斧定位引导故障——全程无需人工盯屏。

决策全部留痕

引导协议为何从 Multiboot2 改为 Limine、字模为何选 Terminus、arm64 为何只占位——六条 ADR 逐条记录背景、备选与后果。

配额治理

开源组件登记制：Limine 头文件（BSD-2）+ Terminus 字模（OFL 1.1），合计 <2%，上限 25%；vendored 原始包带 SHA256 校验记录。
