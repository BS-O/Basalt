[*] 为什么值得读、值得写

[+]三语言严格分层
汇编只做入口桩，C 守硬件边界，C++ 只出现在子系统层；跨语言一律 extern "C"。 [+]headless 可验证
make check 十五秒冒烟断言串口输出，全程无需人工盯屏。
[+]决策全部留痕
六条 ADR 记录引导协议、字模、工具链等决策的背景、备选与后果。 [+]配额治理
开源组件登记制：Limine 头文件（BSD-2）+ Terminus 字模（OFL 1.1），合计 <2%，上限 25%。

[$] 三秒上手

$ cd /mnt/d/Basalt # WSL2 Debian $ make && make iso # kernel ELF → bootable ISO $ make check # CHECK PASSED: hello world on COM1

一切构建与运行均在模拟器/隔离环境中，不写真实磁盘引导区。
