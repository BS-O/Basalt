[*] 为什么值得读、值得写

[+]三语言严格分层
汇编只做入口桩，C 守硬件边界，C++ 只出现在子系统层；跨语言一律 extern "C"。 [+]位图内存管理
Limine memmap 驱动的 4KiB 帧位图分配器，meminfo 命令实时可查。
[+]bsh 交互 shell
PS/2 键盘 + framebuffer 回显，help/ver/echo/meminfo/plugins/halt 命令。 [+]插件机制
启动与 shell 横幅均报告插件数；0 个插件时提示去 GitHub 搜 'basalt plugin'——生态由此起步。

[$] 三秒上手

$ make && make iso # kernel ELF + hello plugin → bootable ISO $ make run # boot log → bsh shell (ps/2 keyboard) $ make check # CHECK PASSED: M1 boot log on COM1

一切构建与运行均在模拟器/隔离环境中，不写真实磁盘引导区。
