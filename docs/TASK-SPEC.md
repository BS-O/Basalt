## 系统基本信息

- 系统名：Basalt
- 实现语言：C++ 为主，C 用于底层/ABI 边界，~~汇编用于引导与上下文切换~~ **汇编用于 64 位入口桩与未来的上下文切换（M0 仅入口桩）**
- 目标架构：x86（32 位与 64 位）为主体；arm64 仅做"兼容预留"，不实现完整功能
- ~~引导方式：8086 汇编入口 → 16 位实模式 → 转 32 位保护模式 / 64 位长模式~~
  **引导方式：Limine 引导程序完成固件初始化（BIOS/UEFI→16位→32位→64位长模式、页表构建、内核装载）；Basalt 自身代码从 64 位长模式入口开始。原任务书中的 8086/16 位切换段由 Limine 而非 Basalt 实现。**
- ~~引导协议：Multiboot2~~
  **引导协议：Limine Boot Protocol（Limine 现行版本已移除 Multiboot2 支持，ADR-002）。**

## 开源配额

- Limine 引导程序本体：运行时外部组件，**不计入 25% 配额**（与编译器/QEMU 同类，口径沿用原 GRUB 判例）。
- `limine.h` 协议头（vendored 进仓库）：**计入**，BSD-2-Clause，约 350 行，占比 <1%。
- Terminus 字模（转换后的数据文件）：**计入**，SIL OFL 1.1，约 4KiB，占比极小。
- 其余代码 100% 自研。合计远低于 25% 上限。
