# ADR-001：遗留代码归档至 legacy/，从零重设计

- 状态：已接受（2026-11-15，用户拍板）
- 背景：`D:\Basalt` 存在一套旧内核骨架（Multiboot2/GRUB 路线，含调度器、内存管理等超出最小范围的模块）。用户新任务书要求最小启动架构，且明确表态"不用现有的代码，重新设计草案"。
- 决策：原内容整体移入 `legacy/` 存档（不删除任何文件），根目录重新搭建新骨架。
- 后果：历史可追溯；新目录树干净；`legacy/` 不参与构建、不计入任何配额与代码量统计。
- 备注：归档期间发现 DSH 沙箱"工作区内禁止删除"保护会拦截移动操作，经用户切换完全权限后完成。
