# ADR-006：arm64 仅占位，不实现

- 状态：已接受（2026-11-15，用户拍板）
- 背景：任务书要求 arm64 仅"兼容预留"。用户确认占位形态为"目录 + README + 接口头/编译桩"。
- 决策：`arch/arm64/` 与 `boot/arm64/` 各留 README 声明设计意图；架构无关接口（console sink、pmm 接口）以条件编译留出对接点；**不编写任何 arm64 汇编、启动代码或驱动实现**；构建系统不含 arm64 目标。
- 后果：未来移植时新增 `arch/arm64` 实现与 `boot/arm64` 引导层即可，内核主体（kmain、console 抽象、lib）无需重构；本里程碑零 arm64 工作量。
